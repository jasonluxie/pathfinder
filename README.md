# React Pathfinding Experiment

This project is a pathfinding visualization application built with React, TypeScript, and Vite.

## Purpose

This application was created primarily as an experiment to explore:
1.  **Dynamic DOM Generation**: Building a grid of HTML elements that automatically scales and populates based on the user's screen size.
2.  **Algorithm Visualization**: Using the generated grid to visualize pathfinding algorithms.

## How it Works

- The application calculates the available viewport area.
- It generates a grid of `div` elements (nodes) to fill the screen.
- These nodes are then used as the graph for pathfinding algorithms.

## Tech Stack

- React
- TypeScript
- Vite

## Running the Project

To run this project locally:

1.  Clone the repo.
2.  Install dependencies: `npm install`
3.  Start the dev server: `npm run dev`
